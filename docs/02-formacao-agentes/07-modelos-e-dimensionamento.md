# Modelos e dimensionamento por tarefa

Origem: seção 14.1 do módulo 14 (material parcial).

O material propõe escolher a capacidade do modelo conforme o trabalho:

1. Raciocínio aprofundado para arquitetura, concorrência e problemas críticos.
2. Engenharia de código para implementação.
3. Baixa latência para operações rápidas.
4. Execução com pesos abertos em infraestrutura própria, conforme suporte efetivo.
