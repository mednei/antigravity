O que é o Antigravity Lab?

O Antigravity Lab é um projeto educacional voltado para o aprendizado prático de desenvolvimento com inteligência artificial. Criado para aproximar conceitos modernos de computação do público geral, o laboratório demonstra que programar não precisa ser uma barreira intransponível quando você compreende a lógica, os agentes e o controle de versão.

Quais problemas o curso resolve?

Muitas pessoas com ótimas ideias travam na complexidade técnica inicial ou se perdem gerando código com IA sem saber como estruturá-lo, corrigi-lo ou colocá-lo no ar. O curso preenche essa lacuna ensinando métodos de prompts precisos, arquitetura limpa de arquivos e rotinas práticas de publicação no GitHub Pages.

PILARES DO CURSO

Metodologia fundamentada na prática.

Como estruturamos a transmissão de conhecimento para garantir aprendizado efetivo.

1. Experimentação Contínua

A teoria só ganha significado quando aplicada. Em cada aula, o aluno realiza um exercício que transforma um conceito em algo palpável no computador.

2. O Humano no Comando

A inteligência artificial atua como assistente ágil de execução, mas as decisões de produto, arquitetura e controle de qualidade continuam sendo suas.

3. Boas Práticas e Versionamento

Desde o início, você aprende a organizar seus arquivos em pastas padronizadas e a utilizar o Git para salvar e proteger seu histórico de trabalho.

HABILIDADES ADQUIRIDAS

Conhecimentos que você desenvolverá:

  • Compreensão do ecossistema Google Antigravity e plataformas de IA.
  • Formulação de prompts detalhados e orientados a resultados técnicos.
  • Estruturação semântica com HTML5, CSS3 moderno e JavaScript modular.
  • Técnicas de inspeção e depuração de código com as ferramentas do navegador.
  • Comandos essenciais de Git (status, add, commit, push, pull, switch).
  • Configuração e publicação gratuita de páginas no GitHub Pages.
